# سیستم‌عامل شخصی

کارگاه صفحه‌به‌صفحه برای بازترکیب بدن، روتین روزانه، مکمل‌های موجود و عادت.

## باز کردن

1. فایل را از همین ریپو باز کن:

```
index.html
```

2. کارگاه اصلی:

```
workshop-personal-os.html
```

پیشرفت و یادداشت هر صفحه در مرورگر همان دستگاه ذخیره می‌شود. دکمهٔ فهرست، ادامه، پرش به ناتمام، و دانلود گزارش هست.

## چه چیزی اینجا نیست

مدارک پزشکی، نسخه، وام، و راهنماهای فنی شبکه در این ریپو نیستند.

## هشدار

آموزشی است، نه نسخهٔ پزشکی.
